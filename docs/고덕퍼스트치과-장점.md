# 고덕퍼스트치과 장점 정리

> 홈페이지(`src/components/home/*`) 전반에서 강조하고 있는 고덕퍼스트치과의 핵심 강점을 정리한 문서입니다.

## 1. 대표원장의 전문성 (핵심 차별점)

**이동현 대표원장 — 통합치의학과 전문의 (보건복지부 인증)**

- 보건복지부 인증 **통합치의학과 전문의** — 임플란트·보철·보존(신경치료)·잇몸치료 등 치과 전 분야를 통합적으로 진단·치료할 수 있는 전문의
- **조선대학교 치과병원 외래교수** — "치과의사를 가르치는 치과의사"
- 치의학 석사
- 서울대학교 치의학대학원 임플란트 치의학 우수상 수료
- 서울대학교 치의학대학원 고급치의학 수료
- **오스템 · 포인트 · 덴티스** 임플란트 연구자문위원 (국내 대표 3사)
- Pennsylvania Univ. 근관치료과정 수료
- ATC Implant Advanced 과정 수료
- KAYA 치과병원 Prosthetic Course 수료
- JPDA 소아치과 임상연수회 수료
- 턱관절장애교육연구회 수료
- 대한통합치의학 학회 정회원

## 2. "처음부터 끝까지 한 사람이 책임지는" 진료 철학

- **담당 의사가 바뀌지 않음** — 상담 → 수술 → 사후관리까지 대표원장 1인이 일관되게 책임
- 슬로건: *"처음부터 제대로, 끝까지 책임지는 치과"*
- **고덕 에듀타운 첫번째 치과** (Since Open) — 처음부터 이 자리를 지켜온 치과
- 페이지 전반에서 반복 강조: "대학병원 외래교수 출신 원장이 직접 상담하고 직접 수술"

## 3. 풍부한 임상 경력 (숫자로 보는 강점)

| 지표 | 내용 |
|---|---|
| 1,200건+ | 컴퓨터 분석 기반 **디지털 임플란트 수술** 경력 |
| 2,000건+ | **사랑니 발치** 경력 (대학병원급 난이도 포함) |
| 대학병원 | 외래교수 역임 |
| 보건복지부 | 통합치의학과 전문의 인증 |

## 4. 최신 디지털 장비 & 시스템

- **3D CT** 정밀 진단
- **디지털 구강 스캐너**
- **디지털 가이드 수술 시스템** — 컴퓨터상 가상수술 → 최적 식립 위치 설계 → 1mm 오차 최소화, 최소 절개
- **OSSTEM 유닛** 완비 진료실
- 별도의 **수술실** 보유
- **통증완화시스템**: 가글마취, 무통마취

디지털 가이드 수술의 이점:
- 시술 시간 단축
- 통증·부기 최소화
- 뼈이식 최소화
- 수술 **직후 임시치아 제공** → "치아 없이 지내는 날 하루도 없음"

## 5. 전 분야 통합 진료 (One-Stop)

통합치의학전문의 1인이 전 분야를 커버하므로, 케이스별로 여러 치과를 전전할 필요가 없음.

| 진료 분야 | 세부 강점 |
|---|---|
| **임플란트** | 디지털 가이드 수술, 통증완화, 수술 직후 임시치아, 대표원장 직접 수술 |
| **틀니 / 전체 임플란트** | 정밀 맞춤 틀니, All-on-4/6, 임플란트 틀니(오버덴쳐), 보험 적용 틀니 |
| **충치 / 신경치료** | 자연치아 보존 최우선, "발치 대신 살리는" 치료, 보험 적용 |
| **사랑니 발치** | 수평·완전매복 등 대학병원급 난이도 가능, 3D CT 정밀 진단, 원스톱 |
| **잇몸치료 / 스케일링** | 특수장비 활용, 페리오클린 관리, 연 1회 보험 적용 |
| **턱관절 치료** | 교합안정장치(스플린트), 물리·약물치료, 전문의 직접 진료 |
| **치아 미백** | 오스템 뷰티스 시스템, 1회 시술 즉시 효과, 스케일링 동반 할인 |

## 6. 환자 편의 & 경제성

- **합리적 가격** + 보험 적용 항목 최대 활용
- **무이자 할부** 및 이벤트 운영
- **65세 이상 건강보험 적용** (임플란트 2개, 틀니 등)
- 무료 **AI 상담**으로 방문 전 예상 견적 확인 가능
- 수술 직후 임시치아 제공으로 일상생활 유지
- 통증완화시스템으로 치과 공포 경감
